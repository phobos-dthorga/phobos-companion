**Which version of the Companion you are running**, and whether a newer one is waiting.

- The version and the commit it was built from. The status bar shows the version too; pressing it opens this page.
- **A newer version waiting**, with the full path of its installer when it is built.
- **What this version brought**, from its changelog.
- **Where it lives:** the program, the repository it was built from, its own records folder, and the [tool kit](term-tool-kit) it uses.
