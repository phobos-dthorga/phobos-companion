**Which version of the Companion you are running**, and whether a newer one is waiting.

In four tabs:

- **This version:** the version and the commit it was built from (the status bar shows the version too; pressing it opens this page); **a newer version waiting**, with the full path of its installer when it is built, and the tab marked **newer waiting**; and **what this version brought**, from its changelog.
- **Where it lives:** the program, the repository it was built from, its own records folder, and the [tool kit](term-tool-kit) it uses, with where that came from: installed with the program, or the repository it was built from. Beneath it, a button opens [which other programs the tools use](task-other-programs).
- **What it asks the internet:** each kind, the address it contacts and whether it is on, with **Going online settings** to change them (see [choose what the Companion asks the internet](task-going-online)).
- **Built with:** the libraries it uses, and their licences.

### Keys
- **I** opens About.
- **;** and **'** step to the tab before or after; **Alt + 1** to **Alt + 9** jump to a tab by its place. **Left** and **Right** move along the tabs when one has the keyboard. Each tab is a step of the trail, so **Back** returns to the tab you left.
