**How the game's memory behaves while you play.** A watch follows what the game holds every 5 seconds, without pausing it, and says whether it climbs steadily or in jumps.

- **Start a … watch…** for 5 to 60 minutes (it asks first, always). **Mark it** with what you're doing as you go, so the figures can be read against it. **While a watch runs, Ctrl + Alt + M marks the moment from the game**, without leaving it (since 0.98.0; change the key in Settings). **Stop the watch now** at any time; nothing is lost.
- Kept watches can be opened again, and found with [Go to anything](task-find-anything).

### Keys
- **U** opens Memory. On the page: **T** starts, **B** marks, **X** stops.
