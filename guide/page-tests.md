**The in-game tests waiting for you**, from each repository's test list.

The rows are on shelves:

- **Seen working:** the game noted these running without an error. Only you can say whether they looked right.
- **Waiting:** nothing has been seen of these yet; try them when you are ready.
- **Your verdicts:** what you pressed, waiting for an agent to write it into the test list.
- **Done:** the test list already says passed or failed.
- **To look into**, and **Notes with no row**, when the game noted something no row covers.

Each row says **What to do** and **What passes**. Press **Passed** or **Failed**, add a note if you like, or **Take it back**.

### Keys
- **4** opens Tests.
