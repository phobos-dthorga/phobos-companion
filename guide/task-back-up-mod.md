---
title: Back up a mod before trying something
kind: task
go: mods
words: backup, copy, save mod, safe
see: term-backup, task-go-back
---
1. Open **Mods** (the **5** key) and find the mod.
2. Press **Back up the installed copy**, then **Yes, back it up**.

This works while the game runs. You rarely need it: **every install already backs up** the copy it replaces.
