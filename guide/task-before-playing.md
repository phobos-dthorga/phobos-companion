1. Open **Mods** (the **5** key). The **Before you play** panel is at the top.
2. If it says a mod needs a build, press **Build now**. Building is safe while the game runs.
3. If it says mods have changes not installed, **close the game**, then press **Install everything that changed**.
4. If it says a mod in the repository has never been installed and you want it, press **Install for the first time** (also with
   the game closed), then turn it on in the game's mod list. **Install everything that changed** never installs a new mod.
5. If it says textures need encoding, press **Encode their textures** (also with the game closed).
6. When it says **Ready to play**, start the game.

Every install keeps the copy it replaces as a [backup](term-backup), so you can always [go back](task-go-back).
