Sometimes only a mod's README or changelog has changed since you installed it, and nothing in play.

1. Open **Mods** (the **5** key), on the **Installed and backups** tab.
2. At the top, under **When only a mod's docs differ**, press one:
   - **Show as an update** (the first choice, as before): such a mod says **The repository has more**, and **Before you play** asks you to install it like any other change.
   - **Show quietly**: its card says **Only its docs differ; nothing in play changes**, and Before you play only notes it, so **Ready to play** can still show.

The choice is kept in this window and stays until you change it. Either way the mod's entries and **Show the files** are still there, and **Install from the repository** still works. A mod counts as docs-only only when every file that would change is a doc, no build waits, and the installed copy has no entries the repository lacks.
