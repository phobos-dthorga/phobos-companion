**Two keys, one for everything and one for the page you are on.**

### Everything: /
1. Press **/** anywhere.
2. Type a few letters of what you want. It looks through pages and their tabs, your mods, changelog versions and entries, recent commits, code, test rows, days on the Timeline, settings, reports, memory watches, and everything this Guide says.
3. Pick it with the arrow keys and **Enter**. A mod opens on the Mod list's **Edit the list** with it chosen; a commit opens its code.

Type a definition's name, such as **C17_Globemaster**, and the first result offers to **look it up** (see [look up one definition by name](task-look-up-definition)).

You can also paste a Companion [address](term-address) there to go straight to it.

### This page's list: Ctrl + F
On a page with a long list (the Mod list, Reports, Changes, Tests, the Timeline, the Code map and this Guide), **Ctrl + F** puts the keyboard in its filter box. Type a few words: only what holds every one of them stays, and the box says how many of how many are shown. **Escape** empties it. On a page with no list to filter, **Ctrl + F** opens the search for everything instead.
