**Reports → Look up** shows one of your game's definitions (a RimWorld Def, for example) three ways, from its name.

1. Open **Reports** (the **G** key), then the **Look up** tab (**Alt + 2**).
2. Type the definition's name as the game writes it, such as **C17_Globemaster**.
3. Press one of:
   - **Who defines it**: every mod that defines it, which one wins, and every patch that names it. Here **\*** stands for any run of letters and **?** for one, to search.
   - **As written**: the definition as its author wrote it, then each parent it builds on.
   - **As patched**: the definition as the game reads it once every patch has run, and what the patches changed. It needs the file of every definition as patched, which your game writes on request (the update check says how, and how old yours is).

The first look after your mod list changes takes about a minute while the tools read every mod again; after that each takes about a second. It only reads.

The name and the look stay part of the page, so **Back** and a copied address return to them. A game whose tools can't look definitions up yet says so.
