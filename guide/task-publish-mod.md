**A new item always starts private**, so only you can see it until you make it public. Steam must be running and signed in for **The Steam client**; for **SteamCMD**, have your login ready.

1. Open **Publish** (**Shift + W**) and choose the mod.
2. On **Workshop page**, read the page, change it if you like, and press **Save the page**. Commit it.
3. Read **Change note**: that is what Steam will get.
4. Press **Prepare** (**E**). Leave **Build first** pressed to build the mod before it is staged.
5. Press **Upload privately** (**Shift + U**), read the question, and press **Upload privately** again.
6. Open the item (**Open in Steam**, **O**) and check the title, page, cover and visibility. Accept Steam's Workshop agreement if it asks.
7. **Subscribe to it yourself and test it in the game.**
8. When it works, press **Make public** (**Shift + M**), then **Go on**, then **Make it public for everyone**.
9. Press **Read Steam back** (**B**) to mark the version **Released** in the changelog. Commit the catalogue, the changelog and any ID file the tools wrote.

**To update an item later:** raise the mod's version and write its changelog entry, then **Prepare** and **Send the update**. The change note covers every version since the last one sent.
