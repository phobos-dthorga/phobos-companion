On the page that looks wrong, press **!** (or **Something's off**). Where no agent sessions are at work, it makes a report for the
Companion's GitHub page, which you read and send yourself: **the Companion sends nothing.**

1. The page is drawn as it is, with your home folder's name hidden.
2. Say what looks wrong, in a few words (optional, but it helps), and press **Show the report**: the report is shown whole, with
   the page's name and the Companion's, the tool kit's and Windows' versions. Nothing else goes in it.
3. Press **Open on GitHub**. The picture is saved in your Pictures folder, in **D'thorga Companion**, and GitHub's new-issue
   page opens in your browser, filled in.
4. Drag the picture into it, read it over, and press **Submit new issue** there, or close it. You need a GitHub account to send it.
