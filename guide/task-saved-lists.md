1. **Close the game and RimSort** first: loading waits until both are closed.
2. Open **Mod list** (the **S** key) and press **Saved lists**.
3. **To keep your list:** type a **Name**, then press **Save the list**. If the name is in use, press **Replace the one with that name**, or choose another.
4. **To load one:** find it under **Saved by name**, **Kept at each game start**, **From your saves** or **RimSort's history**, and press **Compare**. Or press **Open a file…** for a list file.
5. Read what loading would do: how many mods switch on, switch off and move, and which are **not on this PC**, each with why.
6. Press **Use this list**, or **Not now**. A backup of your list is kept first, and **Undo the last change** takes it back.

**Mods not on this PC are left out.** Press **Open in Steam** or **Find on the Workshop** beside each, subscribe, then load the list again to add them.

**To share a list:** press **Save as a file…**. It writes the game's own kind of list file (.rml), which the game's mod menu can load too.

A copy of your list is kept by itself each time the game starts with a different list, the next time the Companion reads it. Once the game has run on it and closed with no new errors, it is marked **Ran clean**. **Go back to the last list that ran clean** compares the newest such list with yours; **Use this list** loads it.
