---
title: Tell an agent that something looks wrong
kind: task
words: bug, wrong, broken, report, screen note, problem, !
see: term-screen-note, task-save-picture
for: agents
---
1. On the page that looks wrong, press **!** (or the **Something's off** button).
2. The page is drawn as it is. Add a few words if you like (they're optional); **Ctrl+Enter** saves.

The picture, the page's address and your words are kept, and **the next agent session reads every open note when it starts**. Home lists the notes still waiting, and the newest ones dealt with, saying how.
