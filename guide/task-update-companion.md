---
title: Install a newer version of the Companion
kind: task
go: about
words: update companion, new version, installer, upgrade
see: page-about
---
1. Open **About** (the **I** key), or press the version in the status bar.
2. If a newer version is waiting and its installer is built, the page gives its full path.
3. **Close the Companion**, then run that installer.

If the installer isn't built yet, ask an agent session to build it.
