---
title: Backup
kind: term
words: backup, backups, restore, copy
see: task-go-back, task-back-up-mod, term-install-record
---
A whole copy of an installed mod, kept so you can go back to it. **Every install makes one** of the copy it replaces, and **Back up the installed copy** makes one on request.

Backups are named for the moment they were made, never deleted unless you choose to, and each carries the changelog it was installed with, so the Companion can say what going back would change. A backup that repeats the one before it is marked, and **Remove repeated backups** clears those.

The Companion's own records have a separate backup: see [records](term-records).
