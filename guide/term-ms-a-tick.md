**Milliseconds a tick** is how long the main thread spent on the simulation for each tick of game time. It needs D'thorga Framework running, which counts ticks and frames as the game plays.

It is the fair way to compare two recordings: a share of time moves when the game runs faster or slower, but milliseconds a tick only moves when each tick costs more or less. Compare recordings of the same save, map and speed; the Performance page says when two are **not like for like** (another save, another speed, other mods' settings).
