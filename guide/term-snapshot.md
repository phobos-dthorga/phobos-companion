A **snapshot** is a copy of a running game's memory at one moment, made by Windows. Taking one pauses the game for about half a second; the game then runs on while the [Explorer](page-explorer) reads the copy. Nothing in the game is changed.

A snapshot costs memory while it is held, so it is let go after ten minutes, when you press **Let it go**, or when you leave the page.

Every snapshot gives everything a new **address** (a number such as `0x1629EFD6E98`), so a thing found in one snapshot cannot be opened from another: take a new snapshot and find it again.
