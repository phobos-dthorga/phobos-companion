**The status bar along the bottom of every page shows what your computer is doing**, read once a second:

- **CPU**: how busy the processors are.
- **Memory**: how much is in use.
- **Disk**: how much is being read and written each second, every disk together.
- **Network**: how much is being received and sent each second.

Each has a **tiny graph of the last minute**, the newest at the right. Within it, the coloured part, and the **Companion …** beside it, is what **the Companion and every program it started** are using: the tool kit's reports, an agent and its commands. So when things feel slow, you see at once whether it's the Companion's doing or something else's. **Hover over one** for the details, such as disk reading and writing apart.

**Network has no Companion share**: Windows says how much each network card carried, not which program it carried it for.

In a narrow window, the graphs fold away and the values stay. Reading the computer costs very little: about 16 thousandths of a second each second, on the owner's PC.

This is your whole computer. To see what is using a *game's* memory, see [find out what is using my game's memory](task-find-memory-use).
