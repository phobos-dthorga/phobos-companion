**phobos-modkit**, the shared set of tools the Companion and the agent sessions use to read logs, saves, changelogs, code and more. The Companion asks it every question and shows its answers; it never runs another author's code.

**The Companion's installer brings its own copy**, with a Python of its own to run it, so nothing else need be installed (except git). On a PC where the Companion runs beside the repository it was built from, it uses that repository's copy instead. Each repository keeps its own copy at a chosen version (its **pin**). About says which version the Companion uses, and where it came from.
